# TomatoMall-Frontend

## 简介

番茄书城前端代码。

## 使用

通过 git 拉取到本地。每次修改后，进行提交，提交时要清晰地说明本次修改的日期及具体内容。

例如：

> 3.26 更新日志
> 
> 1. 修改……
> 2. 实现……
> 3. 优化……
